# 复算漫画对白的识别结果

在仓库根目录运行以下命令，可以从每页的 OCR 标注重新算出整句匹配数。计分脚本仅用 Python 3 标准库，在 Windows、macOS 或 Linux 上都可以运行。

```sh
python3 tools/score.py
```

Windows 如使用 Python 启动器，可运行 `py -3 tools/score.py`。脚本按自身位置找到数据，也接受自定义评测目录，例如 `python3 tools/score.py ./evaluation`。

## 比较什么

同一套横排测试漫画有 6 页，覆盖车站问路、购买车票、确认班次、找洗手间、与朋友碰面和询问失物。每页有 4 个预先写好的日文句子，共 24 句。每格一个对白框，页面布局固定。两组实验使用同一套苹果 Vision 文字识别工具。

| 处理方式 | 输入尺寸 | 样本上的整句完全匹配数 |
| --- | --- | ---: |
| 缩略图识别（A） | 将图像缩至 400 × 245 后识别 | 22 / 24 |
| 原图识别（B） | 在 1600 × 980 原图上识别，阅读时缩放显示 | 24 / 24 |

计分脚本读取已保存的识别结果，复算的过程无需 Mac 或 OCR 服务。要重新执行识别，可在 Mac 上用项目的单页图片转换工具分别处理每页目录内的两张 PNG，再对照新生成的标注。

## 怎样计分

[ground-truth.json](./ground-truth.json) 保存每个场景的日文原稿。每个 `page-N` 目录中的 `preview.mokuro` 和 `sample.mokuro` 是 JSON 格式的标注，分别来自缩略图和原图。脚本从每个文字框的 `lines` 读取对白。同一页内，每个识别结果最多匹配一句原稿，文字和标点都相同才计分。计分允许识别器以不同顺序返回文字框。

[results.json](./results.json) 记录页码与场景的对应关系，以及首轮测试的逐句结果。脚本逐页比对重新算出的分数和文本，检查报告是否遗漏场景、重复页码或与数据文件不符。全部通过时输出以下最后一行。

```text
合计 6 页 / 24 句：缩略图 22/24，原图 24/24。
```

缩略图在第 1 页漏掉一句，第 3 页有一个错字。分数代表这组同版式横排样章的文本匹配结果。对白框位置、竖排版式、手写字体以及实际读者的学习效果，需要单独验收。
