# 安装、导入和故障排查

## 先打开阅读器

首次体验可直接打开[在线样章](https://archao7.github.io/manga-yomikaeri/)。离线时，下载仓库 ZIP，先解压再双击 index.html。样章、页面样式和程序已经在这一个文件里。阅读时不需要账号、API Key 或后台服务。本项目已在 macOS 26.4 的 Chrome 中验证。

## 用随包样卷试一次多页阅读

1. 在阅读器展开「导入自己的漫画」，选择 `examples/volume/volume.mokuro`。
2. 在「漫画原图（可多选）」同时选择同一目录的三张 PNG，然后按页面上的打开按钮。标注是 JSON，里面记着图片文件名、尺寸、对白和坐标。
3. 在前两页各收藏一句，切到「复习本」，用「回到原处」分别回看。第三张空白页也能正常浏览。关掉网页后，使用同一浏览器和入口，重新选中同一卷标注及原图即可找回记录。

## 用自己的扫描 PDF 或图片

1. 将漫画放在 Mac 上可写的文件夹中。双击仓库根目录的「导入自己的漫画.command」，选一本 PDF 或一张 JPG、PNG。
2. 第一次运行需要 Apple 的 Swift 命令行工具。若提示缺少工具，打开终端执行 `xcode-select --install`，完成系统安装后重试。已有 Xcode 或命令行工具的用户可直接运行。[Apple 安装说明](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools)
3. 等待终端显示标注路径。转换 PDF 会在原文件旁创建「文件名-点读」目录，里面有每页 PNG 和 volume.mokuro。转换单张图片会生成同名 .mokuro。
4. 在自动打开的阅读器内选择标注，然后选择配套图片，再打开该卷。可以在同一浏览器中订正识别原文和保存自己的释义。

如果希望直接使用命令，可在项目目录运行下列示例。第二条命令的目标目录应为新的目录。

```sh
swift tools/ocr-page.swift "我的漫画.jpg" "我的漫画.mokuro"
swift tools/ocr-pdf.swift "我的漫画.pdf" "我的点读本"
```

## 常见问题

| 现象 | 解决方式 |
| --- | --- |
| 双击 index.html 后看见源码 | 先将 ZIP 解压，再用浏览器打开文件。也可从项目首页进入在线样章。 |
| .command 无法双击运行或权限不足 | 打开终端，输入 `zsh` 和一个空格，将该 .command 文件从 Finder 拖入终端后按回车。文件选择器会打开。 |
| 提示文件名或尺寸不匹配 | 保留识别时的原始文件名和图片大小。PDF 转换后选择生成的 PNG。失败时可以继续阅读当前书页。 |
| 用修改过的漫画得到旧标注 | 转换工具会复用已有标注。把新版原图或 PDF 另存为新的文件名后再转换，旧书卷及其复习记录仍可通过旧标注打开。 |
| 找不到之前的词卡 | 在创建收藏时使用的浏览器、同一入口重新选择同一份标注及相应页图。隐私浏览、本地存储限制、清除浏览数据或换设备都会影响记录。 |
| 自己导入的漫画没有中文释义 | 可展开「填写我的释义」手工添加。内置样章的中文是预先编写的。 |
| 页面没识别出文字 | 阅读器会保留原图。已验证范围为清晰的横排日语测试页；可从清晰原图重新处理。 |
